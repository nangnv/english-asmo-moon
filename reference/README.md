# Tài liệu tham khảo nội bộ

PDF gốc không phát hành cùng repo public. Ngân hàng câu hỏi đã biên tập nằm trong `src/bank.json`.

Chỉ khi cần nhập lại, chủ dự án đặt PDF 40 câu và đáp án vào `reference/asmo-grade6-practice.pdf`, cài Python + pypdf, rồi chạy `python3 scripts/import-bank.py` từ thư mục gốc repo. Đối chiếu thay đổi câu hỏi và đáp án trước khi commit.

Các PDF trong thư mục này được Git bỏ qua; không cần chúng để chạy ứng dụng hoặc kiểm thử.
