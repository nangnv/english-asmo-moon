- asmo-welcome.png — Chào đón / onboarding
- asmo-study.png — Đọc sách / từ vựng
- asmo-listening.png — Luyện nghe

- asmo-try-again.png — Động viên thử lại
- asmo-rest.png — Nghỉ ngơi / chưa có hoạt động

Use object-fit: contain; preserve the original aspect ratio and alpha transparency.
These are static rendered assets, not a rigged 3D model or animation.
